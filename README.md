## What it does

`main.py` (Python standard library only) writes a single sentence — the one line
that could have replaced an entire pointless meeting — to `/output/entry.txt`.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

## Entry

> This meeting could have been an email, and that email could have been deleted unread.
